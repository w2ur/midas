# backtester/requirements.txt — the Cloud Run service's own pinned closure.
#
# The root requirements.txt is the full monorepo closure (6 workflows, local
# dev, sandbox, the agents). The backtester service imports only bt, fastapi,
# uvicorn, pandas, pandas_ta, pydantic, yaml and yfinance — installing the full
# closure put ccxt, plotly, streamlit, pydeck, lxml and pytest in the image for
# nothing, on a service whose cold start is dominated by pulling its own image.
#
# Every version here is copied verbatim from the root requirements.txt, so the
# image runs exactly the versions CI tests — this file narrows the package set,
# it never resolves versions independently. Regenerate after a root lock bump:
#   pip install bt fastapi uvicorn pandas pandas-ta pydantic pyyaml yfinance
#   pip freeze  ->  intersect names with ../requirements.txt, keep its pins
#
# THIS LIST MUST BE THE COMPLETE CLOSURE, not just the direct dependencies.
# Until 2026-08-05 it was not: markdown-it-py, mdurl, pygments and rich were
# pulled in transitively (rich <- curl_cffi and scikit-learn) and therefore
# installed UNPINNED, which is precisely the reproducibility hole the root
# lockfile exists to close. They are pinned below, at the root lockfile's
# versions, which is what the image was already getting by luck.
# ---------------------------------------------------------------------------
